# v1.2 P1-03: independent validation contracts

진행일: 2026-10-03 (Asia/Seoul). 기준 checkout은 v1.1.0의
`6659a3baa7d84c9025f6d66dfdd421c53334c033`이며, 기존 미커밋 v1.2 변경을
보존한 worktree에서 수행했다. P1-03 acceptance는 완료했지만 v1.2 전체 release
gate를 통과했다는 뜻은 아니다.

## 변경

- `negative_cases.py`가 각 변형 파일을 별도 디렉터리에서 oracle에 전달한다. 원본
  정상 대조군이 먼저 PASS해야 하고, 각 malformed 변형은 독립적으로 거부되어야
  한다. 이전 변형의 실패가 다음 변형을 대신 통과시키지 못한다. 입력 파일이 없으면
  `NOT RUN`/exit 2를 출력한다.
- `run_tests.py`는 launcher JSON의 target signal과 process exit, `collector.ok`를
  함께 확인한다. 정상 대조 실행에는 fault artifact가 없어야 한다. `FD_LAUNCHER`가
  없을 때 다른 직접 실행 경로를 대신 사용하지 않고 `NOT RUN`을 보고한다.
  `PASS`/`FAIL`/`NOT RUN`은 각각 exit 0/1/2다. negative oracle 결과와 실패 stdout/stderr도
  report에 포함한다.
- v0.9/v1.0 standalone gate도 `NOT RUN`을 exit 2로 반환한다. MCP protocol 실패에는
  수신 response, 해석되지 않은 stdout, stderr를 제한 길이로 보존한다.
- gRPC scenario runner는 UTF-8이 아닌 자식 stderr와 timeout output을 예외로 중단하지
  않고 `backslashreplace` 형태로 report에 남긴다. 해당 진단 처리 회귀 테스트를 CTest에
  추가했다.
- `negative_cases_contract.py`, `validation_status_contract.py`,
  `grpc_runner_contract.py` 및 CTest 등록을 추가했다. 새 Python gate는 설정한
  `FAULTDEBUG_PYTHON_EXECUTABLE`로 실행된다.

대표 명령은 다음과 같다. acceptance 산출물과 v10/v09 raw JSON은 gitignored
`build-v12-baseline/p1-03/` 아래에 보관했다. `manifest.json`에는 변경 source/test와
대표 report/CTest log의 SHA-256이 기록돼 있다.

```bash
PATH="$PWD/.tools/bin:$PWD/.venv/bin:$PATH" \
FAULTDEBUG_REAL_CC="$PWD/.tools/bin/clang" \
FAULTDEBUG_REAL_CXX="$PWD/.tools/bin/clang++" \
FAULTDEBUG_RUNTIME_DIR="$PWD/build-v12-baseline" \
FD_LAUNCHER="$PWD/.venv/bin/python -m faultdebug.cli" \
  .venv/bin/python test/run_tests.py --suite acceptance \
  --build build-v12-baseline \
  --output build-v12-baseline/p1-03/runner-acceptance

.venv/bin/python test/v10_validation.py \
  --python .venv/bin/python \
  --build-dir build-v12-baseline \
  --grpc-build-dir build-v12-baseline \
  --install-prefix build-v12-baseline/p1-03/v10-final-install \
  --ctest-dir build-v12-baseline \
  --output build-v12-baseline/p1-03/v10-final
```

P1-03는 계획의 독립 negative/MCP/runner 계약을 충족했다. P1-01/02/03으로 M1을
완료한다. 1800초 soak, P2 수집·측정, portable 외부 비교, CI 전체 release gate 및
독립 감사는 아직 수행하지 않았으며 v1.2 릴리스 판정은 보류다.
