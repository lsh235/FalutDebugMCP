RUN THE REAL FIXTURE

Try it on your machine.

Linux x86_64 + local Docker Engine and Compose. The script downloads a checksummed prebuilt image, runs 8 services and opens a local report server. No host Python, Clang or CMake installation.

git clone https://github.com/lsh235/FaultDebugMCP.git
cd FaultDebugMCP
./scripts/try-demo.sh

The runner uses your local Docker socket to create and remove its own fixture containers. Ctrl+C stops the report server. Existing output directories are never overwritten.

CHECK THE EVIDENCE

Useful findings. Visible limits.

The shopping app is Python with an instrumented C++ boundary. These are native boundary events, not Python stacks. A stable snapshot can still be incomplete; the payment crash keeps that limitation visible.
