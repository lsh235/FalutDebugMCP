# Getting help

- **Bug reports:** use the [bug report form](https://github.com/lsh235/FaultDebugMCP/issues/new?template=bug_report.md).
- **Feature ideas:** use the [feature request form](https://github.com/lsh235/FaultDebugMCP/issues/new?template=feature_request.md).
- **Questions and design discussion:** use [GitHub Discussions](https://github.com/lsh235/FaultDebugMCP/discussions).
- **Security issues:** follow [SECURITY.md](SECURITY.md); do not post exploitable details or real fault artifacts publicly.

When asking for help, include the FaultDebug version, OS/architecture, Python and
Clang versions, a minimal synthetic reproduction, and sanitized output. Do not
attach private source, credentials, or unsanitized `.fault` artifacts.
